# Objective

Replace the incorrect prompt-as-asset UI with the approved model: reusable materials are inserted into a composed task prompt as references. Rebuild the page to match `docs/web/workspace-layout.md` and use actual local shadcn/ui-compatible components.

## Delivered

- Reusable assets have explicit category/metadata and are inserted into the task composer as `@asset` references.
- The server validates referenced asset IDs and snapshots both authored prompt and expanded prompt in SQLite.
- The UI has a left materials rail, independent prompt composer, toolbar, task history, and image result grid.
- Local UI primitives are imported from `web/src/components/ui/`.
- Phase 1 remains text-only; image upload is disabled.

# api-001 复审（api-001-1）

日期：2026-09-01
范围：`docs/INDEX.md`、`docs/web/README.md`、api-001/jobs-001、`server/`、`src/db/`、`src/jobs/`、`server/api.test.ts`、`package.json`。未修改 `stickers/` 或 `stickers_archived/`。

## 结论：blocked

发现两个会阻断 api-001 交付的 P1 集成/安全问题。现有针对性测试通过，但覆盖不足，不能据此判定 pass。

## Findings

### P1 / blocking — 生产静态托管存在路径穿越

位置：[server/index.ts:26-30](../../../../server/index.ts#L26-L30)。生产 fallback 将 URL pathname 直接传给 `join(dist, requested)`，未做 basename/realpath 边界校验。因为 pathname 以 `/` 开头，`join` 会把它规范化到 `dist` 之外；例如 `/../package.json` 可解析为项目外路径（本地验证：`join("/tmp/dist", "/../package.json")` 得到 `/tmp/package.json`）。只要目标文件存在，`Bun.file()` 就会被直接返回。这违反 api-001 的生产静态文件边界，也可能泄露源码/配置文件。API output route 的 basename 校验不能覆盖静态托管 route。

等级：blocking；修复应限制请求路径在 `dist` 内，并对静态文件只允许预期资源/安全解析结果。

### P1 / blocking — worker 启动未在监听前完成，启动错误也未被接通

位置：[server/index.ts:16-20](../../../../server/index.ts#L16-L20)。`startServer()` 调用 `void startGenerationWorker(app.worker)` 后立即执行 `Bun.serve()`。设计合同要求“初始化/migrate SQLite 并 start worker before listening”；`worker.start()` 虽同步执行 stale recovery，但其 continuous drain Promise 未被 await，且启动 Promise 被 `void` 丢弃。这样监听时 worker 尚未完成启动流程；未来/当前 drain 异常会成为未处理 rejection，服务器仍继续对外提供服务。该生命周期集成也未由 `server/api.test.ts` 覆盖：测试只创建 handler，不证明 accepted job 会继续通过实际 server worker 执行。

等级：blocking；应明确 await worker 启动/恢复，再调用 `Bun.serve()`，并补真实 `createServer`/fake generator 集成测试。

### P2 / non-blocking — shutdown 会关闭数据库而不等待 active provider/output finalize

位置：[server/index.ts:34-35](../../../../server/index.ts#L34-L35)、[src/jobs/worker.ts:27](../../../../src/jobs/worker.ts#L27)。`stop()` 只设置 `stopped=true`，不等待 `active`；shutdown 随即 close DB 并 stop server。若 provider 调用或文件落盘正在进行，随后 `finalizeRequest()` 会访问已关闭数据库，可能留下 running request/item 和已写入但未注册的 output。合同没有明确要求优雅等待时限，但这削弱 durable recovery 语义，建议提供可 await 的 stop/graceful shutdown。

### P2 / non-blocking — 静态路由会把任意未知路径 fallback 到 index.html

位置：[server/index.ts:24-31](../../../../server/index.ts#L24-L31)。所有非 API、非现有文件路径都会返回 `dist/index.html`。若这是 SPA fallback 设计，应只对明确的 frontend route 使用；否则任意资源 typo 也得到 HTML（200），并掩盖静态资源缺失。该项不如上述路径穿越直接，但应在生产 smoke/路由合同中明确。

### P2 / non-blocking — API 路由匹配允许 malformed asset suffix

位置：[server/api.ts:48-52](../../../../server/api.ts#L48-L52)。`GET /api/assets/:id/anything` 会命中 `GET` 分支并返回 asset，因为 GET 分支未要求 `parts.length === 3`；合法合同只定义 `/api/assets/:id`。应对每个 route 做精确 segment 匹配，避免额外路径被误当作合法资源。

## 覆盖与剩余不确定性

- `server/api.test.ts` 没有覆盖完整资产 archive/update/get/list、job list/detail/cancel/retry 的请求矩阵，也没有覆盖真实 server 生命周期、生产静态文件、成功 worker 继续执行、content-type/path edge cases。

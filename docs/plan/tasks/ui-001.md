## Requirements

- Build a functional `/` route with asset sidebar, text asset create/edit/save, prompt draft, parameter controls, submit, durable history, progress, cancel, retry, result preview/download.
- Use TanStack Query for server state and active job polling that stops on terminal states. Refresh must restore active history.
- Use Zustand only for current draft state; distinguish asset save from per-job prompt override.
- Include loading, empty, busy, error, and narrow-window states. Do not display local paths.
- Keep frontend free of API credentials and reference-image controls in Phase 1.

# ui-003 Review 1

## Conclusion

**pass** after one fix. An independent reviewer examined the diff and raised five items; four did not hold
up against the code, one did and was fixed.

## Findings that changed the code

- **Reuse could silently replace generation settings.** `reuseJob` only compared prompt text, so clicking
  reuse while the prompt happened to match the job's prompt overwrote model/aspect/size/count the user had
  just changed without asking. Fixed: while the composer is in use, reuse asks whenever the prompt *or*
  any option differs; an untouched composer still applies immediately.

## Findings rejected, with evidence

- "`UnreferencedImagesDialog` never clears `unreferenced`, so the dialog stays open" — it does clear it
  before `submit.mutate()` (`web/src/main.tsx:444-447`).
- "Repeated clicks on 用作参考图 can run concurrently" — every result button is disabled while
  `useOutputAsReference.isPending` (`outputPending` prop).
- "Reference tokens do not verify the alt name against the upload name" — by design. The token ID is the
  identity, both for `referencedImageIdsFromPrompt` and for the server; the alt text is display only.
- "`clearPrompt` leaves dirty state" — the cleared state (`prompt: ''`, `referencedAssetIds: []`) is
  exactly what submission needs to send no references.
